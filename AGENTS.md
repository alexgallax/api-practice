# Проект API-автотестов для бэкенда сервиса Симулятор Инфузионной Помпы

Проект содержит автотесты на API бэкенда сервиса Симулятор Инфузионной Помпы.
Сам тестируемый сервис находится в отдельном репозитории.
Для тестирования запросы выполняются на внешнее API сервиса: [Swagger](https://ips.alexgallax-edu.ru/docs).

## Технический стек

1. Язык программирования: Python 3
2. Фреймворк тестирования: Pytest
3. Библиотека для выполнения API-запросов: Requests
4. Описание и валидация запросов и ответов: Pydantic 2
5. Отчеты о прохождении тестов: Allure (allure-pytest)

## Структура проекта

1. Все автотесты находятся внутри папки `tests/`.
2. Фикстуры автотестов находятся в файле `tests/conftest.py`.
3. Код, не являющийся тестом, находится в папке `src/` (api-клиенты, модели данных, тестовые данные и т.д.).

## Запуск автотестов

Запуск автотестов выполняется командой из корня проекта:

`python3 -m pytest`

Для запуска и отладки тестов в конкретном файле, используется команда
(`имя_файла` заменить на реальное имя файла):
    
`python3 -m pytest имя_файла`

Для запуска и отладки конкретной тестой функции, используется команда
(`имя_файла` заменить на реальное имя файла, `имя_функции` заменить на реальное имя функции):

`python3 -m pytest имя_файла::имя_функции`

## Основные правила и ограничения

1. Не выдумывай требования, шаги, ожидаемые результаты.
   Все должно быть обосновано задачей и полученной фактической информацией.
2. Не запускай весь набор автотестов без явного требования пользователя.
3. Если недостаточно информации для дальнейшей работы или принятия решения, прерви работу и спроси пользователя.
   Не пытайся самостоятельно додумать следующие шаги.
